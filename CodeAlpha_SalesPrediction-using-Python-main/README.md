# Sales Prediction using Python

## Overview

This project predicts future sales based on advertising spend across various platforms such as TV, Radio, and Newspaper.
Using a simple machine learning regression model, it helps businesses understand how advertising budgets impact sales and assists in making effective marketing decisions.

## Objectives

* Predict future sales using advertising and marketing data.
* Prepare data through cleaning, transformation, and feature selection.
* Use regression models to forecast sales.
* Analyze how changes in advertising affect sales outcomes.
* Provide insights for business marketing strategies.

## Technologies Used

* Python
* Pandas for data analysis
* NumPy for numerical operations
* Matplotlib and Seaborn for data visualization
* Scikit-learn for model training and evaluation

## Dataset

The dataset (Advertising.csv) contains details about advertising budgets and corresponding sales figures.
Columns include:

* TV: Advertising budget spent on TV (in thousands)
* Radio: Advertising budget spent on Radio (in thousands)
* Newspaper: Advertising budget spent on Newspaper (in thousands)
* Sales: Sales generated (in thousands of units)

## Workflow

1. Import libraries
2. Load and explore dataset
3. Clean and preprocess data
4. Select important features
5. Split dataset into training and testing sets
6. Train a linear regression model
7. Evaluate model performance
8. Visualize results

## Model Used

A Linear Regression model is used to predict sales based on advertising spending.
Performance metrics used:

* R² Score
* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)

## Sample Output

Visualizations include correlation heatmap, pairplot of features, and actual vs predicted sales graph.


## Results

The model predicts sales based on ad spending across multiple channels.
It can be used to forecast future sales and guide advertising decisions.

## Conclusion

This project demonstrates how machine learning regression techniques can forecast sales and provide actionable insights for marketing optimization.
